# Red vs. Blue v0.1.0

The first versioned release compares 96 economic metrics across Democratic and Republican presidential terms, with source links, uncertainty estimates, and expandable term charts. These comparisons describe historical associations rather than causal presidential effects.

## Changes

- Adds household income, income inequality, official poverty, and historical supplemental poverty measures, with total and annualized changes.
- Includes the preceding observation when measuring a term's change. Partial histories remain available and are labeled; a single observation cannot produce a zero-change result. The [before/after report](https://github.com/wakamex/redvsblue/blob/v0.1.0/docs/change-baseline-comparison-2026-10-03.md) compares all 96 metrics using fixed inputs.
- Shows observation dates in chart tooltips and provides repeatable chart screenshots.
- Links the website to its release notes and records when its data was generated, which code produced it, and the source-input hashes. Weekly refreshes use the deployed release's code.
- Keeps reference papers local and publishes source links and review notes.
